# 考察と 5 分 LT 構成案

データ：Overture Maps places リリース 2026-09-23.1、confidence 0.6 以上、各地区約 1km 四方。

## 目立つ点

1. **大阪・難波は「飲み屋街」**：飲食が 57%（5,526 件中）で 5 地区中最多。飲食のうち酒類を出す店（`alcoholic_beverage_venue`）が 666 件あり、全 POI の約 12% を占める。
2. **バンコク旧市街は「宿の街」**：宿泊が 14% で、他の 4 地区（1〜4%）の 3 倍以上。カオサン通り周辺のバックパッカー街の性格が出ている。
3. **ニューヨーク・ソーホーは「お店の街」より「オフィスの街」**：生活サービスが 48% と突出。中身は専門サービス 452 件、企業オフィス 366 件、不動産 262 件で、ブティック街のイメージに反して事業所が多い。飲食は 12% と 5 地区で最も低い。
4. **京都・哲学の道は宗教が 8% で最多**：他地区は 0〜4%。寺院（`buddhist_place_of_worship`）が 10 件。
5. **パリ・モンマルトルは買い物 25% で最多**：飲食 34% と合わせ、観光と商店が混ざった構成。

## データの偏り

- **総件数の差が大きい**：ソーホー 6,219 件、難波 5,526 件に対し、哲学の道は 190 件（約 1/33）。閑静な住宅地と山すそを含むことに加え、日本の地方部は網羅率が低い可能性がある。
- **神社の分類**：大豊神社が `christian_place_of_worship` に分類されている。神道を表すカテゴリがなく、日本の神社が誤分類されている例がある。
- 「生活サービス」は個人向けサービスと事業所をまとめているため、ソーホーの数字は分類の切り方にも左右される。

## LT 構成案（5 分・7 枚）

1. タイトル：「同じ物差しで世界の街を測る — Overture Maps で街カルテ」
2. Overture Maps とは：世界共通スキーマ、S3 の GeoParquet、無料・登録不要
3. 作り方：DuckDB で bbox だけ読む → taxonomy で 8 分類 → MapLibre（全部 0 円）
4. デモ：画面のスクリーンショット（地区切り替えと比較モード）
5. 結果：比較モードの積み上げ棒 ＋ 難波・バンコク・ソーホーの特徴
6. データの偏り：件数差 33 倍、神社の誤分類 — 「同じ物差し」の限界
7. まとめと次の一手：OSM との差分（現地調査の候補探し）、範囲を自由に選べる版
